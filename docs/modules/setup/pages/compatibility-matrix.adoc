[#asciidoctorjs-compatibility-matrix]
== Asciidoctor.js compatibility matrix

NOTE: This section is intended only for more advanced users who combine extensions or maintain slide decks over many releases and need to update their dependencies.

Each npm package is tied to a specific major version of Asciidoctor.js, because major Asciidoctor.js releases can introduce breaking changes.

Up to the 5.x line, the converter was written in Ruby and transpiled to JavaScript with Opal, so the npm package was built for the matching Opal-based Asciidoctor.js runtime (the `@asciidoctor/core` package, or `asciidoctor.js` before 3.0).
Asciidoctor.js 4.0 was rewritten in pure JavaScript, dropping Opal and the transpilation step altogether, and is published as the `asciidoctor` package.
That rewrite is a breaking change that is not compatible with earlier releases, so the 6.x line is written in native JavaScript and requires Asciidoctor.js 4.x, which you install alongside it (it is a peer dependency).

This table tracks this compatibility.

|===
|Asciidoctor reveal.js version |Compatible Asciidoctor.js versions |Package and range declared in `package.json`

|6.x
|>= 4.0, < 5.0
|`asciidoctor` `>=4.0.0 <5.0.0` (peer dependency)

|5.1.x, 5.2.x
|3.0.x
|`@asciidoctor/core` `~3.0`

|5.0.x
|>= 2.2.4, < 3.0
|`@asciidoctor/core` `^2.2.4`

|4.1.x
|>= 2.2.1, < 3.0
|`@asciidoctor/core` `^2.2.1`

|4.0.x
|>= 2.0.3, < 3.0 (4.0.1: >= 2.1.1)
|`@asciidoctor/core` `^2.0.3` (4.0.1: `^2.1.1`)

|3.x

|`@asciidoctor/core` `^2.0.0` (3.1.0: `^2.0.3`)

|2.x
