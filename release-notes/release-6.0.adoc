== One stylesheet, two moods

This deck itself is themed with *Aurora* — a dark, gradient-accented custom theme for reveal.js, built entirely from CSS custom properties. Restyling it means overriding tokens, not editing component rules.

[.timeline]
* `aurora.css` — the dark theme powering this deck
* `aurora-light.css` — a light variant, same tokens, different values
* Ships in `data/themes/`, part of the `@asciidoctor/reveal.js` npm package — no copying required

See the https://github.com/asciidoctor/asciidoctor-reveal.js/blob/main/examples/aurora-theme/README.adoc[Aurora README] for the full token reference and four example decks.

== Customize

No component CSS to touch — the whole palette, type and shape system is a set of tokens. Override a couple of them with `:customcss:` and the motif follows everywhere it appears.

[source%linenums,css]
----
:root {
  --aurora-violet: #16a34a; // <1>
  --aurora-cyan: #facc15;   // <1>
}
----
<1> Recolors the title rule, code line-highlight, table header underline, stat values, progress bars and timeline rail — every place the gradient motif shows up

That's the same trick `aurora-light.css` uses to flip the whole deck from dark to light: same component rules, different token values. See the https://github.com/asciidoctor/asciidoctor-reveal.js/blob/main/examples/aurora-theme/README.adoc#token-reference[full token reference] for the rest of the palette.
